Test-Failure Triage Assistant

Personal project · 2026

A Python command-line tool that reads a failing test's log, finds the most relevant known-issue notes with embeddings and cosine similarity, and asks an LLM for a diagnosis that cites only those notes. If nothing matches, it says so instead of guessing.

20 pytest tests · CI green · retrieval hit@1 12/12 · triage accuracy 13/13 on synthetic logs
PythonGemini APInumpypytestGitHub Actions
How it works and how I tested it
  • Splits a known-issue file into one chunk per issue, embeds each chunk, and normalizes the vectors so a dot product equals cosine similarity.
  • Returns structured JSON with temperature 0, and drops any citation the model invents that wasn't among the retrieved notes.
  • Treats log text as untrusted data, so instructions hidden in a log can't steer the model.
  • Uses a fake embedder and fake LLM in tests, so all 20 tests run offline in CI.

Built with AI assistance. I set up the environment, ran and debugged every step, ran the evaluation and published it.

RabbitMQ Order-Events System

Personal project · 2026

A producer/consumer system with at-least-once delivery. Database writes are idempotent, so a redelivered message never creates a duplicate order. An Express API with JWT login serves the processed orders.

29 automated tests (Jest + pytest) · CI on Ubuntu and macOS · integration test against live RabbitMQ
Node.jsRabbitMQExpressSQLiteDocker Compose
How it works and how I tested it
  • Direct exchange with routing keys, manual acknowledgement and prefetch of 1 for fair dispatch.
  • Schema validation on both the producer and consumer side.
  • Admin and customer roles: customers only see their own orders, filtered in the database query.
  • Unit tests mock the broker; a separate CI job runs the real producer, consumer and API against a RabbitMQ container.
